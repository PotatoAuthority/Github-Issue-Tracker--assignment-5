
- 1️⃣ What is the difference between var, let, and const?
    `const cannot be changed but var & let can be changed. var can be called above the line it has been declared due to it's function scope`
- 2️⃣ What is the spread operator (...)?
    `Spread operator is used to unpack an array or objects`
- 3️⃣ What is the difference between map(), filter(), and forEach()?
    `map() is used to transform each element of an array`

    `filter() is used to select a particular element from an array based on a condition`

    `forEach() is used to run a function for each elements of array`
- 4️⃣ What is an arrow function?
    `Arrow function is a very short way to write a function`

    ```javascript
    function delete(input){
        //delete
    }

    //the above can be written as:

    const delete = (input) => {
        //delete
    }
    ```
- 5️⃣ What are template literals?
    `Template literals are a way to write multiline string and it also allows to include variable inside strings`
